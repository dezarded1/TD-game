# Last Stand
*Tower Defense на чистом python без движков*

## Геймплей

<video src="screenshots\Last Stand gameplay.mp4" width="640" controls></video>

## Технологии

- Python 3.14.4
- Библиотеки: pegame-ce,numpy,pytmx
- Графика: чистая кодовая отрисовка
- Строк кода: 1000+

## Установка и запуск
1.Клонировать репозиторий:git clone https://github.com/dezarded1/TD-game.git

2.Установить зависимости: pip install -r requirements.txt

3.Запустить игру: python main.py

## Управление

- B - открытие магазина
- Клик по башне в магазине - выбор башни
- Клик после выбора башни - размещение башни
- Esc в игре - пауза
- Esc во время паузы - снятие с паузы
- Esc в главном меню - выход из игры


## Архитектура

- **Система спавна:** непрерывный поток врагов, интенсивность возрастает к концу уровня
- **Враги:** знак доллара ($), цвет меняется динамически в зависимости от уровня здоровья и статуса заморозки
- **Башни:** 4 типа, включая башню с эффектом заморозки (замедление врагов)
- **Механика башен:** установка на поле, радиус атаки, нанесение урона, наложение статусов
- **Система здоровья и монет**
- **Отрисовка:** чистая кодовая графика без игровых ассетов и движков
- **Экраны:** главный экран, экраны победы и поражения с работающими кнопками
- **Объём:** 1000+ строк кода
