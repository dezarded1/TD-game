# Last Stand
*Tower Defense на чистом python без движков*

##Технологии

- Python 3.14.4
- Библиотеки: pegame-ce,numpy,pytmx
- Графика: чистая кодовая отрисовка
- Строк кода: 1000+

##Установка и запуск
1.Клонировать репозиторий:git clone https://github.com/dezarded1/TD-game.git
2.Установить зависимости: pip install -r requirements.txt
3.Запустить игру: python main.py
